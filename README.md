# Rissygraphy

Portfolio website for **Lincoln Kariuki Chege**, photographer and graphic designer based in Nairobi.

The site opens on a realistic 3D model of Lincoln's Nikon D5600, built in code to the proportions of the D3100/D5600 body. As you scroll, the camera turns around, its screen plays back Lincoln's photos, and the view pushes into the screen and rolls into a film reel of his work. From there, visitors can browse the full gallery, read his CV and get in touch.

## Pages

| Page | What it shows |
| --- | --- |
| **Home** (`#top`) | The 3D camera film, a stats panel, a short "Selected work" strip, About Lincoln with his portrait, his services, a CV teaser and contact details. A scene rail on the right marks where you are. |
| **Gallery** (`#gallery`) | 97 photos from three 2026 hikes (Kipipiri, Kathandeni Forest, Lake Ellis), mixed rather than grouped by place. Any photo opens full screen. |
| **CV** (`#cv`) | The full CV with expandable roles, education, skills and languages, plus a **Download CV** button for the PDF. |
| **About** (`#about`) | Lincoln's portrait, story and quick facts on a page of their own. |
| **Contact** (`#contact`) | Email, phone numbers with copy buttons, and links to more of his work. |

Moving between pages closes and opens a camera iris shutter. The first visit opens with a short "Rissy Graphy" ident in the style of a streaming intro; it plays once per visit and can be skipped with a click or key.

Copying contact details, downloading the CV, saving in the editor and losing the connection all report back with a toast in the bottom corner: a small viewfinder readout whose meter runs down until it closes, and pauses while you hover over it.

### Error pages

| Page | When it shows |
| --- | --- |
| `404.html` | Vercel serves it for any path that does not exist. `/gallery`, `/cv`, `/about` and `/contact` are sent on to the matching page instead. |
| `500.html` | A standalone "something went wrong" page to point a host or proxy at for server errors. A plain static deploy on Vercel has no server step, so nothing links to it on its own. |
| In the app | A link to an unknown section such as `#galery` shows the same 404 screen inside the site, and if the site itself crashes while drawing, the 500 screen replaces it with a reload button. |

All three share one look: an out-of-focus photo in a viewfinder whose focus point hunts and never locks.

## Built with

- [React 18](https://react.dev) for the interface
- [anime.js 3](https://animejs.com) for every animation, including the scroll timeline
- [three.js r147](https://threejs.org) for the 3D camera
- [Lenis](https://lenis.darkroom.engineering) for smooth scrolling

All libraries load from public CDNs, so the site has no install or build step to run it.

## Run it locally

Serve the folder from a local web server, then open the address it prints:

```bash
npx serve .
```

Opening `index.html` straight from disk also works, but the camera's screen stays dark because browsers block local photos inside 3D scenes.

## Deploy on Vercel

1. Go to [vercel.com/new](https://vercel.com/new) and import this repo.
2. Set the framework preset to **Other** and leave the build command empty.
3. Click **Deploy**.

`vercel.json` sets long-term caching for the photos.

## Editing the site

There is no visible edit button. Open the editor with the keyboard shortcut:

| System | Shortcut |
| --- | --- |
| Windows / Linux | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>E</kbd> |
| macOS | <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>E</kbd> |

On a phone or tablet, tap the orange dot after **Rissy Graphy** in the nav bar three times quickly. Press <kbd>Esc</kbd> to close it.

The editor changes the background photo behind every page and how bright it is, the intro text, About section, services, the whole CV and photo captions, and previews changes live.

- On the published claude.ai page, saved edits go to the page's shared storage and every visitor sees them. Only people with edit access can save.
- On any other host (including Vercel), the editor appears only on `localhost` and saves to that browser.

## Project structure

```
index.html          the built site (generated by build.js)
404.html, 500.html  the error pages (generated by build.js)
build.js            joins and compiles the files in src/ into index.html and the error pages
vercel.json         Vercel settings
src/
  shell.html        page shell and all styles
  error.html        template for 404.html and 500.html, styled from shell.html
  core.js           shared helpers: smooth scroll, slide-in reveals and toast()
  data.js           photo list, captions and CV content
  content.js        editable content defaults and save/load
  Resume.jsx        reusable <Resume data={...} pdfHref="..." /> CV component
  Camera3D.jsx      the 3D camera, its scroll timeline and the film reel
  app-head.jsx      nav, stats, gallery, lightbox and shutter transition
  Admin.jsx         the editor panel
  app.jsx           About, CV page, contact, scene rail, error screens, toasts and page routing
  meta.json         size and camera settings for each photo
img/                full-size photos
thumb/              grid-size photos
cv/                 the CV as PDF and Word
```

## Making changes

Edit the files in `src/`, then rebuild:

```bash
npm i typescript    # once
node build.js       # writes index.html, 404.html and 500.html
```

The scroll beats for the camera scene live in `SEG` at the top of `src/Camera3D.jsx`. The camera move, captions, screen playback, letterbox bars and timecode all read from it, so changing one number keeps everything in sync.
